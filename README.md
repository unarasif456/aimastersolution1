# Aimastersolution1

Aap ek expert web developer aur UI/UX designer hain. Mujhe "AI Master Solution" naam ki ek professional website banani hai jo logon ko AI tools istemal karna sikhaye aur unki madad kare.

**Website ka maqsad:**

Beginners aur professionals ko AI ka sahi istemal sikhana, AI tools ki guide dena, aur roz marra ke kaamon (writing, business, study, coding, design) mein AI se faida uthana sikhana.

**Pages jo chahiye:**

1. Home page: hero section, tagline, "Get Started" button, features ka khulasa

2. AI Tools Directory: categories ke saath (Writing, Image, Video, Coding, Business, Education), har tool ka naam, description, aur link

3. Tutorials / Learn AI: step-by-step guides aur prompt examples

4. Prompt Library: ready-made prompts jo copy kiye ja sakein (copy button ke saath)

5. Blog: AI news aur tips

6. About Us

7. Contact page: form ke saath

8. Optional: Free AI consultation / services page

**Design requirements:**

- Modern, clean, aur professional look

- Dark aur light mode dono

- Mobile-friendly (fully responsive)

- Colors: blue aur purple gradient (tech feel)

- Tez loading aur SEO-friendly

- Roman Urdu aur English dono languages ka support

**Technical requirements:**

- HTML, CSS, JavaScript (ya React/Next.js, jo behtar ho)

- Clean, commented code

- Search bar tools aur prompts dhoondne ke liye

- Newsletter signup form

**Aap se kya chahiye:**

1. Pehle website ka complete structure aur sitemap

2. Phir har page ka poora code, step by step

3. Hosting aur domain ke liye guide (beginner-friendly)

4. Website se paise kamane ke tareeqe (ads, affiliate, courses)

Har step simple zubaan mein samjhain, aur pehle Home page ka code do.
